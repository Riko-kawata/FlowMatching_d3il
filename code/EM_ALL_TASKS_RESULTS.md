## 0. 結論

1. **Sorting は画像入力の方が状態入力よりはるかに高い。** Sorting6 は状態 0.4% に対し画像 65.3%、Sorting4 も 42.7% → 70.0% (いずれも Ta=2)。
2. **Inserting は状態入力でも約 60% 成功する。** 状態入力の 4 タスクの中で最も良い。
3. **Stacking は途中で崩れる。** 状態入力では 1 箱目は 58% 置けるが、3 箱そろうのは 7%。画像入力では 35%。
4. **推論時にエネルギーを使う工夫 (best-of-K, Langevin) は効果が無かった** (§3, SORTING4_EM_RESULTS.md §9)。
5. **既定の Phase2 (CD) で成功率が上がるタスクは無い** (§6)。ほとんど誤差内で、Stacking 画像 (Ta=8) は −6.7pt、
   Sorting4 状態は約 −2pt と、むしろ下がる条件がある。
   **CD を原論文の設定に合わせると、Inserting 状態の Ta=8 でだけ上がった (52.9 → 57.7%, +4.8pt)。**
   Ta=2 では上がらず、Stacking 画像は大きく下がった (§7)。
6. 画像入力は §1 では 1 seed だが、§6 で seed 0/1/2 の 3 本にした (Sorting4 画像 Ta=2 で 74%, Sorting6 画像 73%, Stacking 画像 38%)。

## 2. 読み取れること

1. **Sorting は画像入力の方が大幅に高い。** Sorting6 は状態 0.4% に対し画像 65%。
   状態観測では「何番目の箱が何色か」の対応を学びにくく、箱の向き tan(yaw) も発散する
   (SORTING4_EM_RESULTS.md §2b / §3a / §7)。画像なら色と位置が直接見えるので、この問題を避けられる。
   状態観測の側に問題があるという仮説と整合する。
2. **Ta (予測し直すまでに実行する行動の長さ) の効き方はタスクで違う。** Ta=2 が良いのは Sorting4 / Sorting6 画像 / Inserting。
   Stacking (状態) は逆に Ta=8 の方が良く (7.4% vs 4.8%)、画像では差が無い。
   押し動作 (Sorting, Inserting) は接触に敏感で、観測を見ずに長く進むと誤差が溜まる。
   掴んで積む Stacking では、短く区切ると動作の一貫性が崩れる可能性がある (未検証)。
3. **Stacking 状態は途中で崩れる。** 1 箱以上 58%、2 箱以上 27.5%、3 箱 7.4%。画像では 82.5% / 62.5% / 35.3%。
4. **Inserting は 1 個目はほぼ確実 (95〜97%)、2 個目で 81〜85%、3 個そろうのが 54〜60%。**
5. **状態入力の seed 間のばらつきは小さい** (±2pt 程度)。学習の当たり外れより、タスクと観測の差の方がずっと大きい。
6. **画像入力の結果は確度が低い。** 1 seed / 360 ep で二項標準誤差 ±2.5pt。seed 間のばらつきも未確認。

## 3. 推論時にエネルギーを使う試み (Sorting4 状態)

再学習の前に、Energy Matching らしい推論の使い方を §6 の学習済み ckpt で試した。詳細は SORTING4_EM_RESULTS.md §9。

| 方法 | 内容 | 結果 (Ta=2) |
|---|---|---|
| best-of-K | 同じ観測で K 本のチャンクを作り、エネルギー V が最小のものを実行 | K=2: 効果なし (43.3 → 43.9%, 3 seed × 1080 ep)。K≥4 は悪化 (K=16 で約 −15pt) |
| Langevin tail | サンプリング終盤 (t ≥ 0.8) にノイズを加える | ε=0.1 / 0.3 とも効果なし |

- K を増やすと、V が最小のチャンクばかり選ぶようになって動きが偏り、押しても進まない失敗 (dithering) と時間切れが増える。
- 同じ観測の中での V の大小は、どのチャンクが成功するかをほとんど区別していない。
- `n_action_samples` の既定は 1 のまま (本表の結果もすべて K=1)。

### 6c. まとめ

1. **Phase2 で成功率がはっきり上がる条件は無い。** 14 条件中、差が 2σ を超えたのは Stacking 画像 Ta=8 (−6.7pt, 3 seed とも低下)

   CD だけの効果かを切り分けるには、`lambda_cd=0` で Phase2 を回す対照実験が要る (未実施)。

## 7. 原論文に合わせた Phase2 (2026-10-04 〜 10-05 追記)

§6 で Phase2 が効かなかった理由を調べ、CD を原論文の実装 (`experiments/cifar10/train_cifar_multigpu.py` と README の
Phase2 コマンド) に合わせて Inserting 状態と Stacking 画像で試した。

### 7a. §6 の Phase2 が効かなかった理由

原論文と違っていた点:

| | 原論文 (CIFAR) | §6 までの既定 |
|---|---|---|
| 負例 (偽サンプル) の鎖の長さ | 200 step × dt 0.01 = 時間 2.0 | 50 step × dt 0.01 = 時間 0.5 |
| 鎖のノイズ ε | t < 1 は 0、以降 0.01 | 最初から 0.1 で一定 |
| Phase2 の入り方 | Phase1 の ckpt から再開 (optimizer・EMA を引き継ぐ)、2k step、EMA decay 0.99 | AdamW と EMA を作り直し、学習率を warmup から再スタート、10k step |
| 推論 | t = 1 を超えてノイズ付きで積分 (T = 1〜5) | t = 1 で止める決定的 ODE |

負例のエネルギーを Inserting 状態 seed 0 の Phase1 重みで測った (データのエネルギーは −36.7)。

| 負例の作り方 | データ始点の鎖 | ノイズ始点の鎖 | CD 損失の符号 |
|---|---:|---:|---|
| §6 までの既定 (時間 0.5) | −36.6 (データと同じ) | −9.8 (データより 27 高い) | 負 (学習信号なし) |
| 原論文どおり (時間 2.0) | −39.6 (データより 3 低い) | −39.8 (データより 3 低い) | 正 (学習信号あり) |

- 既定の負例は、ノイズ始点の鎖が t = 0.5 までしか進まない途中の点で、最初からデータよりエネルギーが高い。
  CD は「データを下げ、負例を上げる」損失なので、教えることが残っていなかった。
- 時間 2.0 まで流すと、鎖はデータよりエネルギーが低い場所に落ち着く。Phase1 の地形には t = 1 の先にデータから外れた谷があり、
  CD はそこを持ち上げる信号になる。

### 7b. 実験設定

- **学習**: §6 の Phase1 最終重み (生 `em_p1_step*_raw.pth`, EMA `em_p1_step*.pth`) から Phase2 を 2000 step。seed 0/1/2。
  - **CD**: 鎖 200 step × dt 0.01、ノイズは t < 1 で 0、以降 0.01 (`cd_schedule=true, tau_star=1.0, cd_eps_max=0.01`)、`lambda_cd=1e-3`。
  - **対照**: 同じ設定で `lambda_cd=0` (追加の flow 学習だけ)。CD の効果と追加学習の効果を分ける。
  - 学習率は Phase1 の最大値の 1/10 で一定 (状態 3e-5 / 画像 1.5e-5、warmup 100 step)、EMA は Phase1 から引き継ぎ decay 0.99。
    Phase1 の optimizer 状態は保存しておらず、Phase1 は cosine で 1e-6 まで下げているので、学習率だけは原論文と揃えられない。
- **推論**: ODE (従来どおり t = 1 までの決定的 ODE) と SDE (t = 2 まで積分し、t ≥ 1 で ε = 0.01 のノイズ。学習時の鎖と同じ時間)。
  どちらも Euler, dt = 0.05。
- **評価**: §6 と同じ条件・同じ評価乱数。基準は §6 の Phase1 + ODE (`pair_p1_ta*.npz`)。差の `±` は §6 と同じペア標準誤差。
- 投入 `logs/em_all/orchestrate_p2paper.py`、集計 `logs/em_all/summarize_p2paper.py`、出力 `logs/em_all/p2paper/`。
- 追加したオプション (`cd_schedule`, `sample_T`, `phase2_lr`, `phase2_warmup`, `init_ema_ckpt`) の既定値は従来と同じ挙動。

### 7e. まとめ

1. **原論文どおりの CD は、Inserting 状態の Ta=8 で初めて Phase2 の成功率を上げた** (+4.8 ± 2.1pt, 3 seed とも正)。
   対照 (CD なし) は 3 seed とも下がる (−4.5pt) ので、CD そのものの効果は +9.4pt。
2. **ただし最良値は更新していない。** Ta=2 では差が無く (−1.8 ± 2.1)、CD + Ta=8 の 57.7% は Phase1 + Ta=2 の 58.9% と同水準。
3. **Stacking 画像では CD が flow を崩し、成功率が半減した** (35.5 → 18.5%)。CD 損失が flow 損失より大きかったのが原因と考えられる。
   `lambda_cd` を下げた追試は §7f。
4. **t = 2 までの積分 (SDE) は全条件で悪化する** (Inserting −12 〜 −24pt、Stacking は Phase1 で 0%)。
   CD 後は Stacking で 0 → 6.9% まで戻るので、CD は t > 1 の地形を直す方向に効いているが、2000 step では足りない。
   今回の範囲では推論は ODE (t = 1) のままが良い。
5. **CD なしの追加学習だけで両タスクとも −4.5pt 下がる。** val flow は変わっていないのに下がる。
   §6 の既定 Phase2 での小さな悪化も、CD ではなく学習し直し自体が原因だった可能性が高い (§6c の 4 への回答)。
